# 헬퍼손 면접 실습 (banin)

경기지방고용노동청 반도체 딥다이브(2026.10.23) 「AI 시대의 면접 트렌드」 특강용 실습 웹앱 최종본입니다.

- 실행: `index.html` 하나로 동작합니다(서버·DB 없음, 입력 내용은 브라우저 localStorage에만 저장).
- 구성: ① 면접자 평가 / ② AI 면접 컨설팅(5단계) / ③ 질문 만들기(직무별 질문 은행 · NCS 직무역량 · 기출·후기)
- 파일 업로드: txt·md·csv·html·한글(hwp·hwpx)·워드(docx), 드래그앤드롭 지원. hwp·hwpx·docx 읽기 도구(jszip·cfb·pako)는 처음 사용할 때 jsDelivr CDN에서 내려받습니다.

## data/ (앱에 내장된 데이터의 원본)

| 파일 | 내용 | 출처 |
|---|---|---|
| `db.json` | 삼성전자 DS 2026 상반기 21개 직무, SK하이닉스 2026 하반기 23개 직무 JD | 각 사 공개 채용공고 |
| `ss_raw.json`, `sk_raw.json` | JD 파싱 원본 | 위와 동일 |
| `ncs_semi.json` | NCS 반도체 세분류(개발·제조·장비·재료) 능력단위·요소·지식·기술·태도 | 국가직무능력표준(NCS) 엑셀에서 반도체 항목만 추출 |

## 유의사항

- 질문 은행의 예시는 JD·NCS·면접 후기(비공식)를 바탕으로 만든 것이며 실제 출제 질문이 아닙니다.
- 직무와 NCS 능력단위의 연결은 앱 제작 시의 추정 매핑입니다.
- 인재상·전형 방식은 삼성전자·SK하이닉스 공식 채용 안내에서 반드시 확인하세요.
- hwp·hwpx 읽기는 직접 만든 모의 파일로만 검증했습니다. 실제 지원서로 확인 후 사용하세요.
